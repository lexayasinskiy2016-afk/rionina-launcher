# Rionina Launcher

Лаунчер Minecraft в стиле Apple: компьютер (Windows, macOS, Linux) и телефон (Android, iPhone).

## Что умеет

**Компьютер (`/`)**
- Вход через **Microsoft** (почта, телефон или Skype — аккаунт с купленным Minecraft) или **офлайн** по никнейму.
- **Новости** — официальная лента Mojang: новости, обновления Java и Bedrock. Нажмите на карточку, чтобы прочитать полностью.
- **Версии** — все выпуски Java Edition, от `rd-132211` (2009) до последней: релизы, снапшоты, Beta и Alpha, с поиском.
  «Установить» → версия скачивается и сама появляется в «Мои версии».
- **Играть** — запускает выбранную версию. Если версия не установлена, лаунчер сначала её установит.
- **Java ставится сама**: нужная версия (8, 17, 21…) скачивается с серверов Mojang.
- **Bedrock** (Windows 10/11) — устанавливается автоматически при первом запуске (через winget из Microsoft Store, нужен аккаунт Microsoft с купленным Minecraft) и запускается одной кнопкой.
- **Скины** — 3D-просмотр, редактор (рисуйте сами), 12 готовых скинов, загрузка PNG. Скин аккаунта Microsoft загружается в профиль Minecraft; в офлайне — виден в одиночной игре.
- **Моды** — каталог Modrinth, сборка Fabric создаётся в один клик, зависимости ставятся сами.
- **Шейдеры** — с Modrinth, Iris и Sodium устанавливаются и включаются автоматически.
- **Ресурс-паки** — Modrinth + свои паки Rionina Smooth и Rionina Clear Glass.
- **ИИ-сборки** — опишите словами, какую сборку хотите: ИИ подберёт моды, модерация проверит (читы, x-ray и 18+ запрещены), сборку можно опубликовать — она появится у всех примерно через 10 минут. С ключом Gemini на сервере (`GEMINI_API_KEY`, бесплатно) подбирает нейросеть.
- **Forge и NeoForge** — вместе с Fabric: сборка создаётся одной кнопкой, моды ставятся под нужный загрузчик.
- **Чат с друзьями** — сообщения прямо в лаунчере, мат скрывается.
- **Плащи** — выпадают из сундуков, видны на персонаже в лаунчере.
- **Скриншоты** — F2 в игре, снимок сразу в галерее; важные моменты отмечаются звёздочкой.
- **Серверы** — список любимых серверов с онлайном, пингом и описанием; «Играть» запускает нужную версию и сразу подключает.
- **Профиль** — уровень, время в игре, статистика и 14 достижений с наградами; +10 монет за каждые 30 минут игры.
- **Голосовые звонки** — звоните друзьям прямо из лаунчера и играйте, пока идёт разговор.
- **Английский язык** — переключается в Настройках.
- **Автообновление** — лаунчер сам предлагает «Обновите Rionina Launcher» и ставит новую версию.
- **Rionina ID** — вход по нику и паролю, ник нельзя занять чужим.
- **Друзья** — заявки по нику, статусы, «Разрешить для друзей» (мир открывается через e4mc) и кнопка «Зайти» у друзей.
- **Сундуки** — ежедневная награда в Rionina Coins (50→200 за 7 дней подряд), сундуки за 100/200/500 монет, внутри скины и эффекты.
- **Rionina Pro** ($10, оплата картой скоро): бесплатные сундуки, награда ×2, 50 друзей, Pro-скины, моды на FPS и настроенная Java.
- **Настройки**: несколько аккаунтов, темы, цвет акцента, фон из галереи, память, полный экран, журнал игры.

**Телефон (`/mobile`)** — Minecraft Bedrock:
- Запуск Minecraft одной кнопкой; если игры нет — открывается Google Play или App Store.
- Новости Bedrock.
- Серверы: «Играть» открывает Minecraft и добавляет сервер в список.

## Выпуск обновления

```bash
node scripts/release.js 1.5.0 "Что нового" "Ещё что нового"
```

Скрипт ставит версию, добавляет новость на сайт и отправляет тег на GitHub. GitHub сам собирает Windows-версию и Android-приложение и публикует релиз. Лаунчеры игроков увидят «Обновите Rionina Launcher». Обычно обновление весит ~2 МБ.

Сайт публикуется на GitHub Pages автоматически при каждом изменении папки `site/`. 

## Сервер Rionina и сайт

Папка `server/` — сервер аккаунтов (ник + пароль), друзей, Rionina Coins, сундуков и Pro. Он же отдаёт сайт из папки `site/`.

```bash
cd server
node server.js   # http://localhost:8080
```

Бесплатный запуск для всех: база в Neon (neon.tech, строка подключения → переменная `DATABASE_URL`) и сервер на Render.com по файлу `render.yaml` (Blueprint, тариф Free). Адрес сервера записывается в `site/config.json` — лаунчеры берут его оттуда сами. Бесплатный Render засыпает без запросов, поэтому GitHub каждые 10 минут его будит (`.github/workflows/keepalive.yml`). Пока сервер не запущен, лаунчер работает в локальном режиме: аккаунт с паролем хранится на компьютере, а друзья недоступны.

## Запуск на компьютере

Нужен [Node.js 20+](https://nodejs.org).

```bash
npm install
npm start
```

Установщик: `npm run dist:win` (.exe), `npm run dist:mac` (.dmg) или `npm run dist:linux` (.AppImage) — результат в `dist/`.

Игра и Java хранятся в папке `.rionina`: `%APPDATA%\.rionina` на Windows, `~/Library/Application Support/.rionina` на macOS, `~/.config/.rionina` на Linux.

## Телефон

Нужны Android Studio (для Android) или Xcode на Mac (для iPhone).

```bash
cd mobile
npm install
npm run android      # или: npm run ios
npx cap open android # откроется Android Studio → Run
```

Сборка без своей машины: загрузите проект на GitHub → вкладка **Actions** → «Сборка Rionina Launcher» → Run.
Готовые .exe, .dmg, .AppImage и .apk появятся в артефактах.

## Важно

- Сама Bedrock Edition — платная игра из Google Play, App Store и Microsoft Store. Лаунчер её запускает и открывает страницу установки, но не скачивает сам.
- В офлайн-режиме работают одиночная игра и серверы без проверки лицензии.
- Rionina Launcher не связан с Mojang или Microsoft. Minecraft — товарный знак Mojang AB.
